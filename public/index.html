How AI Agents Pay Autonomously

  1. Agent Initiates Call: Bot sends POST /api/v1/extract.
  2. x402 Challenge: Server responds with 402 Payment Required, specifying price (0.005 USDC) and Base wallet address.
  3. On-Chain Micropayment: Agent broadcasts USDC transfer on Base (network fees < $0.001).
  4. Immediate Fulfillment: Agent replays request with header X-Payment-Proof: <txHash>. Server delivers result instantly.
